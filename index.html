Alcance de esta versión

Etapa 5E de prueba: conserva la administración de productos, clientes, consumos y pagos con cuenta de administrador y la vinculación de teléfonos mediante QR. Permite probar el inicio de sesión de empleados desde teléfonos vinculados seleccionando empleado y usando PIN. El servidor emite una sesión temporal independiente; esta página NO usa esa sesión para consultar ni modificar datos comerciales. La sesión de empleado se conserva únicamente en memoria; si se cierra la página sin salir, el token expira en el servidor según su vencimiento. Para revocarla inmediatamente usá Cerrar sesión. El listado de nombres se obtiene del servidor únicamente con teléfono autorizado. Todavía no hay permisos comerciales de empleado, caja, stock, uso sin internet ni APK. No usar para operar un bar real.
